# 城市未来车厂：新增四款游戏计划（简单操作 · 交互特效科普版）

日期：2026年11月10日  
状态：四款新增游戏、跟手特效、三关、作品记录及六张实物照片已实施；本轮将大厅、八游戏、控件与作品统一改为赛博朋克夜城风格，增加类别筛选、继续体验及手机顶部导航。具体设计见《cyberpunk-redesign.md》。
实施基线：`f911be4`，沿用 TypeScript + Vite + Phaser Canvas，支持离线单文件。

## 目标与体验约定

将“城市未来车厂”扩展为八款独立的汽车与新能源科普游戏。延续现有大厅、三款车辆造型、个人工位和作品报告；新增四款重点设计操作过程中产生的特效：手指或鼠标移动时，光轨、电缆、扫描带和实验轨迹即时跟随，操作对象有吸附、展开、脉冲和回弹反馈。

沿用面向3—6年级、无编程基础的活动定位。新增每款首次体验约8—12分钟，包含30秒上手引导、三个场景、可重复挑战和结算复盘。三关都可直接进入，完成一次核心体验即可获得体验章；积分与挑战星级分开，鼓励孩子继续尝试。

本版优先级：**操作容易上手、每次核心交互都有特效、特效帮助理解科普现象、由实物图片或实际视频支撑观察。** 默认操作分别是拖光轨并按住泊车、拖接充电线、拖扫描器并点换件、拖实验滑块并按住双车出发。移动、按住、松开和改变输入都产生即时反馈，孩子持续控制实验过程；系统负责计算运动和结果。

科普体验顺序：**看到现象 → 动手改变 → 看出差异 → 明白一个知识点 → 保存自己的发现。** 孩子的操作实际改变教学模型的结果，动画、星级与作品记录均从同一次运行产生。

150分钟活动建议让学生选择4—6款深入体验，其余作为自由探索入口；八款全部开放，作品报告保留每款的实际体验状态。

## 科普内容怎样进入玩法

1. **开始前只给一个观察目标。** 例如“看看小车为什么需要转弯空间”，短句贴在画面边缘，孩子可立即操作。
2. **操作中把知识画出来。** 传感器用发射与回波示意，路径用车身包络，功率用供电流速，电量用电池填充，故障用链路断点，抓地力用轮迹变化。
3. **变化后出现一句解释。** 控制在约30个汉字，指向刚才变化的位置；不遮挡主舞台，不强制答题才能继续。
4. **“为什么会这样”可展开。** 每款三张小知识卡，每张约40—60字，配一张小图。单位、公式和细参数放在这里。
5. **结束记录一个个人发现。** 由本人的实验条件与结果生成描述，再允许孩子从两条贴合结果的表达中选择或补充一句；未做过的比较不生成“已经发现”。
6. **三关各有一个知识目标。** 场景改变同时带来新的观察内容，避免只更换背景、不断加难度。

所有科学画面标为教学示意，参数采用便于观察的教学设置。资料来源与知识边界见文末，解释不使用真实车型性能承诺。

## 简单操作与交互特效规范

- 默认主要操作不超过三项，使用点击、拖动或一个滑块。复杂参数、键盘驾驶、时间控制等在“进阶工具”中展开。
- 点击操作覆盖拖动：点起点后再点目标也能接线或选部件。拖动目标有大范围吸附区，错误位置可轻松松开重试。按住运行支持空格键，也提供可切换的“开始/暂停”方式。
- 开场只展示目标、一个主要按钮和必要状态，目标是在10秒内开始首次操作。主舞台占游戏内容区域约70%，说明面板默认折叠。
- 画面统一采用赛博朋克夜城风格，照片保持原貌，特效集中出现在正在操作的对象、连接路径或实验结果上。选择、拖动、按住、松开、吸附成功和重试各有明确反馈。
- 首次反馈目标为操作后100毫秒内出现；拖动反馈持续跟手更新。松开后的吸附或回弹约120—220毫秒，关键成功反馈约0.5—1秒。用户再次操作时立即响应。
- 泊车以青蓝光轨为识别色，充电以青绿能量流为识别色，维修以琥珀扫描光为识别色，雨天以冰蓝与橙色双轨为识别色。
- 支持静音和减少动效。粒子、光带和奖励动画属于视觉效果；减少动效时仍保留清楚的状态变化和结果。

### 操作与特效的对应关系

| 用户操作 | 即时特效 | 跟随与结束规则 |
| --- | --- | --- |
| 点选车位或部件 | 点击位置扩散一圈波纹，目标轮廓收拢锁定 | 换选目标时旧轮廓退去，新目标获得高亮 |
| 拖光轨控制点 | 控制点拉出短光尾，路线连续弯曲，车身包络沿路线预览 | 障碍冲突位置显示警示轮廓；松手后锁定当前有效方案 |
| 按住泊车或双车出发 | 出发提示收缩，车轮与轨迹开始运动，沿途出现短粒子尾迹 | 按住才推进，松手立即暂停运动和计时，尾迹自然消散 |
| 拖充电头 | 电缆柔性弯曲跟随鼠标，插口附近出现吸附圈 | 接近有效接口时自动对齐；松开接入，错误位置回弹 |
| 成功接线 | 接口短脉冲沿电缆传到电池，连接卡扣收合 | 随后按实际供电显示连续光流；未接成功时保持未供电 |
| 切换补电策略 | 被选车辆边缘发亮，能量流速度与分配粗细平滑改变 | 光流强弱随实际功率更新，电池填充随实际电量更新 |
| 拖扫描器 | 手势位置形成窄扫描带，经过位置揭示局部剖面与信号节点 | 未扫描区域保持原视图；经过的检测点留下可查看证据 |
| 点开并修复部件 | 部件弹出并轻微回弹，替换时自动吸附，信号逐段点亮 | 选错部件给出局部提示，复测通过才出现完成反馈 |
| 拖实验滑块 | 路面变化、速度预览或轮胎示意随本关变量更新 | 滑块松开时锁定本次条件；运行期间保持条件一致 |
| 拖回放标记 | 两车沿自己的真实轨迹同步回退或前进，差异位置展开放大 | 跟随标记定位记录帧，松开保留当前对比，不重新计分 |

特效与输入直接相连，并有实际状态依据。点击环、尾迹和吸附属于交互提示；测距标签、供电光流、信号链、轨迹与结果表达当前模型。每款至少有一个“拖动时连续变化”的主要交互和一个“完成动作时明显回应”的特效。

### 1. 自动泊车训练营

**体验目标：**让自己在工坊设计的小车完整停进目标车位。

默认操作流程：点目标车位 → 拖发光路线上的转弯控制点 → 按住“泊车”让小车前进 → 松手暂停查看 → 调整再试。转弯标记控制可行路线的选择与空间，系统生成包含前进、倒车与转向的曲线路段。无法通过的路线显示警示包络和原因，保留重新调整入口。

进阶工具可展开方向键与屏幕驾驶按钮。手动与自动演示使用同一运动模型；松开控制即停止输入，切换页面释放按键。

三个场景：宽敞直入车位、倒车入库、路边侧方停车。场地逐渐缩小，并加入静止车辆或锥桶。练习模式可显示参考路线；辅助示范使用同一运动与碰撞模型播放。

**科普内容：**

- 第一关看“测距”：超声传感器发出脉冲并接收回波，用来估计附近障碍物距离。[S1]
- 第二关看“规划”：知道车位位置后，还需要结合车身和转向能力选择可行路线。[S2]
- 第三关看“执行”：计算出的路线需要转向等执行环节完成，随时能暂停查看当前动作。[S2]
- 一句话解释：“汽车先看周围，再算路线，最后控制转向。”

**交互特效：**点击车位时，波纹从落点扩散，四个定位角向车位收拢；抓住路线控制点时，控制点轻微放大，光带跟随拖动弯曲，半透明车身沿可行路线预览。拖近障碍时，该处轮廓发出短警示脉冲。按住“泊车”时小车行驶、车轮转动、沿路径留下光尾，松手即停，光尾逐渐消散。实际入位后定位角合拢，作品卡从车位处展开。

挑战记录：车身是否完整入位、方向偏差、与车位中心的偏差、碰撞次数、操作次数。星级规则在开始前显示，完成判定以车身几何和停车状态为准。

**验收：**拖动标记期间可行路线与光带持续更新；不可行路线能解释原因；按住推进、松手暂停；车不能原地横移或穿过障碍；前进与倒车的转向关系正确；只有实际停入车位才结算；辅助示范和手动驾驶遵守同样的场地约束。

### 2. 充电站小站长

**体验目标：**让排队车辆在各自的出发时刻达到任务所需电量。

默认操作流程：点车辆看补电需求 → 拖充电线到车上 → 点“优先补电”或“均衡补电” → 看能量流与电量增长 → 换一辆车接线比较。车辆停放与补位自动处理，系统在总供电上限内分配功率。

进阶工具再展开逐桩功率滑块、队列调整和模拟时间。基础场景把大部分调度选择藏在清晰的两种策略里，先让孩子理解变化。

三个场景：两车基础调度、多车共享供电、临时加入一辆急需补电的车。关卡使用预先验证过的可完成任务配置。允许暂停、加速播放和重开，儿童不必按现实时间等待。

**科普内容：**

- 第一关区分“速度和数量”：功率描述补电快慢，电量描述存入的能量；以“水流快慢和水箱里有多少水”作类比，精确单位放进知识卡。
- 第二关看“车和桩共同影响”：充电快慢受充电设备与车辆能力影响，电池已有电量、容量、类型和温度也会影响充电时间。[S3][S4]
- 第三关看“共享供电”：在本站总供电固定的教学场景里，给一辆车更多份额会减少其他车可用的份额；这个变化由同一供电模型计算。
- 一句话解释：“充电要看供电有多快，也要看车能接收多少。”

**交互特效：**拖充电头时，电缆弯曲并随手移动，接口附近出现逐渐收紧的吸附圈；松手接入后卡扣合拢，一次脉冲从接头沿电缆跑到电池，随后开始按实际供电播放光流。点选“优先补电”时，被选车辆产生一圈确认波纹，供电分配与线内粒子速度连续改变。点击拔线时接口松开，电缆收回，实际供电停止。电池层格按实际电量点亮。

挑战记录：按需求完成的车辆数、等待时间、实际供电量和调度调整。充电目标按任务需要设定，不要求每辆车都充满。

**验收：**电缆拖动连续跟手，成功接线、错误松手和拔线都有对应反馈；未接线和拔线后不能增加电量；总分配功率不能超过站点容量；每辆车的光流、供电量与电量变化对应；暂停不增加电量；车辆达到目标后可释放充电位；关卡存在可行解。

### 3. 汽车故障急救站

**体验目标：**通过检测找到导致汽车异常的部件，再完成修复和复测。

默认操作流程：拖扫描器扫过车辆 → 查看扫描留下的证据 → 点可疑部件 → 点“更换并复测” → 保存维修报告。扫描带跟随手势揭示检测点，工具自动匹配当前检测步骤，第一关一次只呈现少量候选部件。

进阶工具可展开检测仪选择、信号与供电读数、操作顺序和虚拟资源预算。

三个场景：动力供电异常、传感器信号异常、转向执行异常。首轮为单故障，进阶重玩轮换故障位置和表面症状。每种工单有可区分故障的检测线索与明确的复测标准。

**科普内容：**

- 第一关看“动力链”：教学剖面把电池、电驱部件、电机与车轮连起来，供电故障会影响动力演示。
- 第二关看“感知链”：传感器获取信息，控制单元处理传感器数据，执行器完成相应动作。[S5]
- 第三关看“证据与复测”：同样的异常表现可能有不同原因；通过关卡给出的可区分检测线索定位原因，修复后重跑同一测试。
- 一句话解释：“先找出哪一环出了问题，再换件验证。”

**交互特效：**孩子拖扫描器时，光带紧贴手势移动，只在扫过位置揭示局部剖面、信号节点和检测读数；经过检测点时弹出一枚短暂证据标记。点击部件时，部件从原位置弹出并轻微回弹，连线被拉展开，方便看它连接哪一环。点击更换时旧件退出、新件吸附入位；复测过程中信号脉冲从输入逐段传到输出，模型判断恢复后车身合拢。选错时仅在相关部件出现提示并允许继续检测。

挑战记录：检测顺序、有效诊断证据、替换部件、资源消耗和复测结果。完成分鼓励修复，星级鼓励有证据地定位故障。

**验收：**扫描带随拖动连续变化，证据由实际扫过的检测点产生；部件展开、换件和复测具有不同反馈；故障原因、检测输出和车辆行为一致；替换正确部件后同一模型恢复；猜错不能获得成功维修记录；重开当前工单清除该次临时操作。

### 4. 雨天抓地力挑战

**体验目标：**把同一辆小车开过试验道路，比较不同路面、轮胎和速度下的轨迹。

默认操作流程：拖本关唯一的实验滑块 → 按住“双车出发” → 松手暂停 → 拖轨迹上的回放标记比较 → 修改条件再试。第一关滑块改变路面干湿，第二关改变速度，第三关改变轮胎条件，每关其余条件保持一致。滑动干湿时，路面湿润效果跟随数值推进；滑动速度或轮胎条件时，只更新对应预览。

车辆按同一个转向指令序列行驶；做路面比较时固定车辆、轮胎、起步速度和输入，只改变路面。实验开始后固定条件，修改条件会结束当前运行并开始新一轮，已有轨迹保留为历史对比。

进阶工具可展开轮胎条件、方向控制、路线选择与模型参数。比较轮胎时固定其他条件，只改变轮胎参数。

三个场景：干湿路面的弯道比较、相同湿滑路面上的速度比较、相同条件下的轮胎比较。每关先给可完成的默认速度与路线，再允许孩子修改一个条件观察变化。

**科普内容：**

- 第一关看“轮胎与路面”：轮胎和路面之间的摩擦支持车辆转向、制动与加速；轮胎花纹与路面状态会影响抓地表现。[S6][S7]
- 第二关看“条件匹配”：在不同路面条件下调整速度，并用教学模型观察相同路线的运动变化。[S8]
- 第三关看“对照实验”：每次保持其他条件一致，只改变路面、速度或轮胎中的一项，才能清楚说明这项改变的影响。
- 一句话解释：“轮胎要抓住路面，小车才能按计划转弯。”

**交互特效：**拖干湿滑块时，湿润边界与水纹随手势推进，数值越高，预览雨滴和路面反光越明显；按住“双车出发”时两车同时行驶，接地处出现水花或轮迹，两条轨迹随实际位置不断延长，松手时运动和水花立即停下。抓住轨迹回放标记后，两车同步定位到该时刻，局部放大窗跟随标记滑动，突出转弯差异与方向箭头。重试后旧轨迹淡化保留，新的轨迹随本次实验重新绘制。

挑战记录：驶出道路次数、触碰障碍次数、完成情况，以及同条件比较中的轨迹差异。科普重点是路面与操控的关系；与现有“刹车充电秀”的能量回收主题形成补充。

**验收：**实验滑块的视觉变化持续跟手；按住推进、松手暂停；拖回放标记能连续定位两车历史状态；一轮运行的实验条件固定；在同样输入下改变路面确实改变模型结果；低速练习存在可完成路线；退出停止运动；轨迹、结算和截图来自实际运行。

## 实现安排

沿用现有 TypeScript、Vite 和 Phaser Canvas。公共菜单与文字控件继续使用 DOM，游戏画面复用 `createStage`，车辆图形复用现有 SVG 和 Canvas 绘制接口。

每款拆成独立的教学模型、页面交互和样式，例如 `parking-model.ts`、`parking.ts`、`parking.css`。模型负责位置、供电、故障、关卡结果和可保存数据；画面负责把这些状态绘出来。

公共游戏注册表集中维护 ID、标题、简介、图标、挂载方法和积分上限。扩展 `GameId`、默认状态和记录读取后，大厅与报告根据注册表生成内容。

素材采用实物照片与可交互教学示意并排呈现，沿用超级眼睛的原图放大、扫描、人工标注与来源说明。已加入停车场航拍、车辆充电接口和充电桩实物、电动车底盘展出与车架、汽车轮胎胎面六张获许可照片。观察点只对应实物中可见部位；模型提供光轨、电缆、扫描带、剖面层、轮迹和局部放大视图。照片不生成故障读数或实测数据。新增素材随离线页面内嵌，避免依赖远程图片或在线服务。

科普短句、知识卡、观察目标与资料编号集中放在各游戏的内容配置中。所有数字标签、轨迹、链路和电池状态读取模型数据；装饰性光效在渲染层处理。

交互特效分别响应选中、按下、移动、吸附、松开、取消和完成事件。手势期间持续读取位置与当前模型，松手或失焦立即结束按住输入；快速重复操作取消或更新上次特效，避免旧动画覆盖新状态。移动到元素外、触摸取消和切换游戏均释放输入。

## 验证与完成标准

- 模型测试覆盖泊车碰撞与完成判定、供电容量与电量、故障与复测、路面变化与轨迹，以及重复计分、暂停和重开。
- 使用旧四款存档验证升级，使用全新存档验证八款独立进入。
- 浏览器中实际完成每款至少一关，并验证失败后重试、来回切换、键盘与屏幕按钮操作。
- 每款默认入口在10秒内可开始首次操作，默认主要操作不超过三项；点击方式可完成拖动对应的任务。
- 每款至少一次操作能同时看到模型结果变化、对应视觉反馈和贴合该结果的科普短句。
- 每款至少验证一个连续跟手特效、一个成功完成动作的反馈，以及错误或取消操作时的反馈。
- 验证拖动中反馈持续更新，按住与松开正确推进和暂停；操作到目标外、失焦或切换页面不会残留按住状态。
- 验证快速连续点选、接线、扫描和重试能够立即响应，旧特效不覆盖新状态，也不产生重复奖励。
- 检查点击位置、吸附位置、扫描区域和回放位置与实际指针一致，窄屏缩放后保持一致。
- 验证知识卡可自由展开与收起，说明和奖励不遮挡操作目标，减少动效后仍能看懂结果。
- 使用同条件、不同单变量的记录验证个人发现文案；没有实际完成比较时不生成比较结论。
- 检查1366×768、1920×1080和窄屏布局，确保主要控件可见，画面不被说明面板遮挡。
- 验证下载报告包含实际八款状态，图片与本人作品相符；打印和PNG导出正常。
- 验证六张实物图在线与断网解码、原图完整等比显示、拖动扫描连续跟手、场景观察重点切换、来源与合成截图导出；原图弹窗正确暂停或冻结当前操作，加载失败能重试，切换页面不留下旧图片回调。
- 执行项目测试和构建，生成最新“城市未来车厂-双击打开.html”，断网打开并完成代表体验。
- 最终同步代码、离线HTML、说明与验收记录到现有GitHub仓库。

## 科普资料与内容边界

以下资料用于核对知识点；采用自己的教学场景和简化模型。页面短句面向儿童表达，来源放入可展开知识卡和说明文档。

- [S1] [Bosch Park Pilot Ultrasonic Sensors](https://www.boschautoparts.com/documents/647135/656939/Park%20Pilot%20Ultrasonic%20Sensors%20Factsheet.pdf)：超声脉冲、回波、近距离测距。
- [S2] [Bosch Park assist](https://www.bosch-mobility.com/en/solutions/parking/parking-assist/)：车位测量、路径计算、转向执行。来源中的辅助泊车仍需要驾驶者监管，本游戏自动播放仅表示教学演示。
- [S3] [US EPA — Plug-in Electric Vehicle Charging: The Details](https://www.epa.gov/greenvehicles/plug-electric-vehicle-charging-details)：充电速率、设备与车辆能力。
- [S4] [US EPA — Plug-in Electric Vehicle Charging: The Basics](https://www.epa.gov/greenvehicles/plug-electric-vehicle-charging-basics)：电池电量、容量、类型和温度对充电时间的影响。
- [S5] [Bosch — Control units](https://www.bosch-mobility.com/en/solutions/control-units/)：处理传感器信息与控制执行器。故障工单的因果、读数和维修方案为自定义教学案例。
- [S6] [FHWA — Pavement Friction for Road Safety](https://highways.dot.gov/sites/fhwa.dot.gov/files/2023-06/FHWA%20Pavement%20Friction%20for%20Road%20Safety%20Primer.pdf)：路面摩擦与转向、制动、加速。
- [S7] [NHTSA — TireWise](https://www.nhtsa.gov/vehicle-safety/tires)：轮胎花纹、抓地力和不同路面条件。
- [S8] [FHWA — Driving in Wet Weather](https://highways.dot.gov/safety/speed-management/guidelines-use-variable-speed-limit-systems-wet-weather/chapter-2-driver)：根据路况调整速度与行驶路径。
