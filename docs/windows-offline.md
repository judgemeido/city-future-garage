# 城市未来车厂 · Windows 完整离线版

适用系统：Windows 10 / Windows 11，64 位（x64）。

## 单文件免安装版

双击“城市未来车厂-双击运行.exe”直接进入游戏，不需要安装、管理员权限或联网。只需复制这个 EXE 到电脑、桌面或 U 盘，全部八款游戏与 Electron / Chromium 运行环境都包含在文件内。

启动时会自动将内置运行环境释放到系统临时目录，稍等片刻即可进入游戏；退出后自动清理临时运行文件。存档仍保存在 %APPDATA%\CityFutureGarage，移动或重命名 EXE 不会丢失本机存档。若换到另一台电脑，需另行备份该存档目录。

运行 npm run package:win:portable 可重新生成此版本，产物位于 release/windows/城市未来车厂-双击运行.exe。

## 安装与使用

双击 CityFutureGarage-Setup-1.0.0-x64.exe，按中文向导选择安装目录，完成后从桌面或开始菜单打开“城市未来车厂”。安装包包含完整游戏与 Chromium 运行环境，安装和运行都不下载内容，不需要浏览器、Node.js、WebView2 或网络连接。

八款游戏、照片、车辆素材、音效、教学说明、作品报告均在本机运行。资料来源的网页链接只用于署名，离线版不会打开互联网；本机素材说明可在“帮助”菜单阅读。

“我的工位”可修改昵称与工位号，游戏记录自动保存在本机。独立安装版使用自己的存档，不会自动读取 Chrome/Edge 或旧 HTML 页面的记录。

“我的作品”可以保存独立 HTML 报告和 PNG 车辆作品，保存时选择文件位置。需要 PDF 时，在作品页使用“文件 → 保存当前页面为 PDF…”或 Ctrl+P，PDF 生成也无需联网。F11 进入或退出全屏，Ctrl+加号/减号调整缩放。

## 存档与卸载

存档目录：%APPDATA%\CityFutureGarage。卸载与覆盖安装保留这个目录，方便以后继续体验。需备份时，关闭游戏后复制整个目录；在另一台电脑上恢复时，同样先关闭游戏再复制。关闭游戏后删除该目录可重置全部桌面版记录。

在 Windows 的“设置 → 应用”中卸载“城市未来车厂”。安装程序会建立桌面和开始菜单快捷方式及卸载入口。

## 制作安装包（开发者）

在源码目录运行 npm ci，再运行 npm run package:win。开发电脑首次构建需要下载 npm、Electron 和 NSIS 构建工具；生成的 EXE 包含运行所需内容，用户安装时无需联网。

产物目录：release/windows。分发给用户只需要 Setup EXE，一个安装文件即可；不要分发开发依赖目录。发布包未配置代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
