# 城市未来车厂：八游戏赛博朋克改造

日期：2026年11月10日。

本轮将体验大厅、八款游戏、我的作品、个人工位和下载成果统一成霓虹夜城风格。继续以“操作触发特效，特效实时跟手”为核心，实景和实物照片维持原貌，知识解释与科学结果仍来自原教学模型。

## 视觉与信息层级

- 深蓝夜色背景，青色作为公共操作色，紫红用于夜城灯光。主要文字使用接近白色，说明文字使用浅蓝灰；霓虹集中在选中项、操作对象和关键结果。
- 八个入口分别绘制霓虹插画，夜城、充电站和车厂使用本地 SVG / Canvas 图形，无新增外部图片请求。
- 各游戏保留识别色：感知与泊车为青色，工厂与维修为琥珀，AI 为紫色，能量回收与充电为青绿，雨天为冰蓝。红绿信号、绿色停车区和双车实验颜色保持清楚。
- 舞台、操作面板、状态条和结算统一深色；实物观察区不覆盖装饰纹理，不对照片施加色彩滤镜。

## 操作与布局改进

- 大厅增加“全部体验 / 创造与训练 / 驾驶与能量 / 感知与检测”筛选，分别对应8、3、3、2个游戏；筛选直接更新入口，保持键盘焦点。
- 显示八枚体验章进度、每款积分与已体验状态。“继续探索”记住当前浏览器最近进入的游戏，游戏内原有记录自动恢复。
- 桌面保留左侧导航；手机改为顶部横向滚动导航，动效、声音与工位在独立工具行，释放主画面的宽度。
- 主要操作按钮至少44px；选中、按住、成功、错误、禁用与键盘焦点均有明确状态。增加“跳到主要内容”入口，直接聚焦当前页面。
- 感知照片按窗口可用高度等比收缩，设置面板独立滚动。四个实物实验在窄屏依次显示舞台、主要操作、状态和实物照片。
- 下载HTML报告、工坊海报和车辆PNG使用同一夜城主题；打印采用浅色纸面布局。

## 实现位置

- `src/theme.ts`：舞台公共夜色背景及游戏识别色。
- `src/cyberpunk.css`：公共布局、导航、大厅、按钮、作品和移动端主题。
- `src/visuals.ts`：大厅夜城与八游戏入口 SVG。
- `src/main.ts`：筛选、最近体验、状态展示、导航与报告导出。
- `src/games/*`：各游戏的场景绘制、控件、结果及实物观察边框。

## 验收

自动化浏览器检查覆盖大厅、全部八游戏和作品页，宽度1440、390、320px；检查页面宽度、Canvas比例、深色主题、主要按钮尺寸和对比度、筛选、最近体验、键盘焦点、导航、原图与独立报告。感知另检查1920×1080、1920×900、1440×900、1366×768、1280×720下主图完整显示。

互动回归继续验证十二个新增场景的光轨、按住/松手、扫描、错误换件、接线/回弹、功率、雨天变量和历史回放，以及原四游戏与六实景照片。最终数量、离线构建哈希及具体结果见根目录《验收记录.md》。
