# 造车工厂：六部件选装与完整参数图

工厂的电池、逆变器、电机、减速器、车轮和车身各有三种配置。按钮、参数图中的部件支持选装；主图以纯色背景只展示车辆，去掉工坊背景、机械臂、部件托盘和叠层标注；三套参考方案分别用于通勤、重载爬坡和长途巡航。车辆颜色和名称继续由学生自己决定。

工程预算、整备质量、轮端功率、扭矩和保存车辆按钮放在主图右上角的整车数据浮动面板中，右侧选装区不重复显示。拖动面板标题可移动，范围限制在主图内；标题聚焦后方向键移动，Home返回右上角，Escape关闭。关闭后点击“显示车辆数据”重新打开；位置和关闭状态保存在本机。窗口缩放自动适配边界，试跑时隐藏面板。小屏的数据区可滚动，保存按钮固定在面板底部。

## 参数与模型

| 部件 | 可比较的参数 | 试跑中的作用 |
| --- | --- | --- |
| 电池 | 24 / 40 / 60 kWh；28 / 85 / 65 kW；400 V | 可用电量、最大直流供电、质量 |
| 逆变器 | 输入45 / 100 / 160 kW；效率94 / 96 / 98% | 直流输入限额、直流到交流的损耗、质量 |
| 电机 | 60 / 90 / 140 kW；140 / 210 / 280 N·m；6000 / 8500 / 11000 r/min | 机械功率、低速扭矩、转速上限、质量 |
| 减速器 | 7 / 9 / 12∶1；效率97 / 95 / 93%；输出承受1800 / 2500 / 3800 N·m | 转速降低、扭矩增加、传动损耗、质量 |
| 四轮 | 低阻城市轮、均衡抓地轮、大径旅行轮 | 有效半径、滚阻、前驱轴抓地上限、四轮质量 |
| 车身 | 城市车、旅行跨界车、电动赛车 | 基础质量与风阻面积CdA |

所有参数为合成教学值。轮胎标称规格帮助认识轮胎，其教学有效半径独立列出。抓地与滚阻分别影响驱动力上限和路面阻力，不表达任何实车轮胎测评。

整备质量是六大部件质量之和，加45 kg固定设备；试跑再加入75 kg驾驶员和路线载荷。每次试跑从65%电量开始，附件耗电700 W。电机效率随负载在84–90%变化，图中保守轮端功率上限采用84%。逆变器功率是直流输入限额，电机功率是机械输出限额，因此不能直接把两个数当作同一侧功率比较。

轮端扭矩取电机扭矩×传动比×传动效率与减速器承受上限的较小值。驱动力还受轮端功率、车轮有效半径和抓地限制，前轴法向载荷按整车55%简化。坡度采用反正切转换后计算重力与法向力。转速上限给出运动学车速上限；这个数不是实测极速，空气阻力和供电会进一步限制真实试跑。转速实验滑块也遵守当前配置的转速上限。

## 存档与验证

旧配置保留名称、车身、有效电池与电机选择，补齐100 kW逆变器、9∶1减速器和均衡抓地轮。积分、最佳星级与历史试跑继续保留。新版指纹包含全部六部件并带`powertrain-v2`前缀，只有新版的不同配置可做同路线能耗对照，避免把两个教学模型混成部件差异。

模型与选装表：`src/games/factory-model.ts`；图与规格：`factory-parameters.ts`；界面、车辆展示与作品：`factory.ts`。

`npm test`包含供电限额、能量守恒、传动比爬坡取舍、轮胎能耗差异、参考配置可达性和旧车升级。`node scripts/check-factory.cjs`验证真实按钮、键盘、转速示意、保存刷新、PNG/SVG下载、任务星级、同路线对照与320–1920px布局。支持`QA_URL`指定开发服务或离线文件，使用仓库已有Playwright运行环境。
