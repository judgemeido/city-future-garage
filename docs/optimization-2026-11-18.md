# 2026-11-18 项目优化与单文件交付

本次检查以当前八游戏版本为准：感知找目标、智驾造车、AI 大脑训练、预测回能、方向盘泊车、智驾诊断、充电知识问答、雨天驾驶，以及大厅和作品页。

## 验收清单

- 十个页面分别检查 1920×1080、1366×768、1280×720、1024×600、800×540、640×600、390×844、320×568：横向溢出、画布比例、开始弹层与侧栏工具可访问性。
- 单独检查初始首屏和实际操作区截图；小窗口允许正常页面纵向滚动。
- 使用真实点击和键盘检查：大厅筛选、昵称存档、六张照片切换/放大、手机天气滑块、造车配置保存、AI 开始暂停、回能驾驶暂停、泊车与方向盘、五节点诊断修复、十道问答结算、雨天制动暂停、作品导出。
- 探索异常路径：从桌面缩到手机时的结算弹层；取消 PDF 保存后再次导出；重复打开同一 EXE；将单个 EXE 复制到带中文和空格的新目录并改名后启动。
- 桌面成品以断网运行验证全部八游戏、六张内嵌照片、昵称持久化、HTML/PNG/PDF 导出、窗口缩小和重复启动。
- 模型准确性使用现有 74 项测试。历史游戏界面专项脚本中的旧控件不作为当前版本验收依据。

## 实现

感知天气工具条允许收缩换行；手机六关缩略图使用横向滚动，减少工作区前的高度。手机游戏开始和结算卡片进入正常布局，防止长文与按钮被画布裁切。矮桌面窗口缩紧页头、按剩余高度等比显示驾驶舞台。侧栏只滚动游戏入口，底部动效、声音与工位工具保持可用。

Canvas 不再每帧读取布局；尺寸由 ResizeObserver 更新，跨显示器的 DPR 改变仍被检测。小画布按显示尺寸分配像素；页面隐藏时停止动画帧，返回时重新计时，保留统一逻辑坐标与输入释放。

开发服务器忽略打包、报告导出和测试输出目录，避免生成离线文件或报告时意外触发游戏页面重载。

构建阶段用 WebP 压缩实际引用的 JPEG，保留原始尺寸与源文件，只替换更小的结果；不改变感知目标标注。删除未引用的 Phaser 依赖，成品没有 npm 运行时依赖。Electron 只打包简体中文和英文语言包，保留 Chromium、GPU/软件渲染与必要 DLL，使用最大压缩。

## 重建与验证

```sh
npm ci
npm test
npm run build
node scripts/check-optimization.cjs
npm run package:win:portable
npm run test:desktop
```

离线页面检查可设置 `QA_URL=file:///C:/Codex/newyy/dist/index.html`；桌面检查可设置 `QA_DESKTOP_EXE` 为便携 EXE 的绝对路径。检查输出位于 `output/optimization/` 和 `output/playwright/windows-offline/`。

单文件 EXE 支持 Windows 10/11 x64，可移动或改名；不要求安装浏览器、Node.js、WebView2 或管理员权限。启动时在用户临时目录释放 Chromium，游戏存档使用 `%APPDATA%\CityFutureGarage`，移动 EXE 后本机记录不变。

## 本次实测结果

- 74 项模型测试通过；开发页面和压缩后的离线 HTML 各通过 80 个页面/窗口组合检查，并完成八游戏主要操作与作品下载。
- `dist/index.html` / 根目录离线 HTML：4,481,755 → 3,415,673 字节，减少约 23.8%；六张照片保持原始尺寸，合计图像数据减少约 26.8%。
- Electron 语言资源：51,195,034 → 1,192,397 字节，减少约 47.7 MiB。
- 便携 EXE：104,966,800 字节，约 105.0 MB / 100.1 MiB。较大的底限来自内置 Chromium 运行库。
- 正式 EXE 断网加载八游戏与照片成功，昵称重载保持；HTML、PNG、PDF 均导出成功，取消 PDF 后可再次保存；重复启动只保留一个游戏窗口。
- 仅复制 EXE 到含中文和空格的目录，并改名为 `移动后重命名.exe` 后成功启动、加载游戏，原测试存档仍显示 `完整离线测试`。
- 已审阅桌面/手机十页面对照图、游戏开始/暂停/修复/问答结算截图及正式 EXE 默认窗口。检查范围内未发现横向溢出、开始或结算按钮裁切、画布拉伸及脚本运行错误。

NSIS 便携启动器不转发 Electron 的 stderr 管道，因此成品 QA 使用本机临时 inspector/CDP 端口连接真正释放运行的程序；仅测试启动参数打开这些端口，正常双击程序不会打开调试端口。中间目录 `win-unpacked` 和移动测试的重复 EXE 因自动审批策略阻止删除而保留，分发时只需主便携 EXE。

## AI 红灯修复与复验

红灯等待计时原来要求车辆接近停止线，但 AI 或人类示范会提前刹停，导致道路停止移动、红灯永远无法变绿。现在车辆停稳后即可完成原有1.1秒等待，学习训练和直接参加全自动路考均可恢复行驶；行人提前停车时也会继续过街。判断窗口从3.5秒延长到5.5秒，画面和动作区显示同一剩余时间，暂停不消耗判断或红灯等待时间，错误示范与原始预测继续保留。

- `npm test`：当前80项模型测试全部通过；上方74项及原始体积数据保留为首轮优化记录。
- `node scripts/check-ai-redlight.cjs`：浏览器七条回归流程通过，包括未学习/已学习的完整六关路考、红灯提前停车与暂停恢复、五秒后示范、5.5秒超时安全接管、错误教学及污染预测、行人提前停车。
- 320px和390px手机视口通过真实触屏按钮示范，红灯变绿后正常重新起步；动作区倒计时可见、可操作。
- 已重新构建根目录离线 HTML（3,416,986 字节）与 Windows 单文件 EXE（104,966,972 字节，约105 MB）。正式 EXE 在断网状态下完成相同七条红灯回归；学习及直接启动均能恢复并完成六关路考，5秒后仍可示范，5.5秒后超时接管，暂停冻结计时，未出现脚本错误。
- `npm run test:desktop` 对新版 EXE 复验通过：八游戏及内嵌照片、昵称存档、HTML/PNG/PDF 导出、取消后重试、窗口缩小与重复启动。证据保存在 `output/ai-redlight/portable-regression.json`、`output/ai-redlight/mobile-regression.json` 和 `output/ai-redlight/desktop-offline/audit.json`。
