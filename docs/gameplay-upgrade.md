# 车型与闯关改进

沿用 TypeScript / Phaser Canvas 和离线单文件输出。此次聚焦新能源车厂：三种独立车身轮廓、途中驾驶事件、即时解释、三星挑战、重玩变化和本地最佳纪录。

实施顺序：
- [x] 用 Node 内置测试验证事件推进、错误重试、重复提交和星级；实现独立挑战模型。
- [x] 工坊接入三段事件、暂停/继续、场景提示、结算复盘、重玩/下一关和存档。
- [x] 更新 Canvas / SVG 车型，城市车短轴距、旅行车高车顶行李架、运动型双门溜背尾翼；缩略图与海报同步。
- [x] 构建、浏览器通关与重试验证、窄屏检查，更新可双击离线文件。

约束：保留原有车辆能耗模型及同条件配置对比。驾驶选择独立决定挑战星级，不伪造能耗结果。三关均可直接进入；错误选择会停留当前事件，解释原因后允许重试。三星需要跑完全程并且三次都首选正确。未完成途中退出不写通关纪录。重新挑战轮换事件并打乱答案位置。旧存档可直接使用。

验证重点：暂停时不能推进事件；答错不能跳过；一题只计一次首选；退出/换配置不残留选择界面；最佳星级只增不减；离线文件包含最新代码。
