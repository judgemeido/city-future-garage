## 2026-11-17 验收结果

最终安装文件：`release/windows/CityFutureGarage-Setup-1.0.0-x64.exe`，126,334,363 字节（约 120.5 MiB）。SHA-256：`45a403d1586481e7a1cf87c688eaeea560834d9a7400d47b96923a773055cdbb`。

通过 TypeScript / Vite 构建及 71 项现有模型测试。实际安装到 `output/windows-install-test/城市未来车厂`，生成桌面与开始菜单快捷方式、中文卸载名称和卸载入口；实际安装后的 EXE 完成 `npm run test:desktop`。

浏览器网络设置为 offline 后重新载入并打开八款游戏；六张感知照片与四款实物观察加载成功，无 HTTP(S)/WebSocket 请求及脚本错误。真实操作修改昵称、规划并保存泊车作品；昵称刷新后保留，另一次重启验证回能记录与截图保留。

HTML 报告、PNG 海报及 PDF 通过本机保存接口落盘并验证文件头、八个报告条目和内嵌图像；取消 PDF 保存后可以再次导出。原始资料链接被离线说明替代，未打开额外网页。默认窗口及 1024×768 窗口截图通过视觉检查，无黑屏、图片缺失或异常横向溢出。

测试安装已卸载：EXE、桌面与开始菜单快捷方式及卸载入口均移除，测试存档保留。安装过程未配置下载器，Electron/Chromium、全部游戏脚本、样式与图像随 NSIS 载荷内嵌。网络断开验证采用 Chromium offline 设置和桌面应用网络拦截，没有改变宿主机网络设置。

完整自动化输出在 `output/playwright/windows-offline/final/audit.json`，截图在同目录。原生菜单的编辑功能、实体打印机、重复启动及不同 Windows 硬件未逐项人工验收；全屏/缩放使用 Electron 标准菜单功能。
